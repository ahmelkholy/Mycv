Updated 9 October 2026. A straightforward academic CV covering teaching,
research, education, technical skills, and verified publications.

Edit the Markdown source and rebuild with:

```sh
python3 build_cv.py
```

Requirements: Python 3, XeLaTeX (TeX Live), and Arial. The build regenerates the
PDF, LaTeX source, and text version. No Python packages are required.

Profile links are saved in [profiles.json](profiles.json). Future update
instructions, source evidence, and unresolved details are in
[UPDATE_NOTES.md](UPDATE_NOTES.md) and [AGENTS.md](AGENTS.md). Publication metadata
is stored in `research/`; the original CV files are preserved in `original/`.
